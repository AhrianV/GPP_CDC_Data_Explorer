Your Flask App

A simple, modular Flask application with Bootstrap, Jinja templating, and organized frontend assets.

Welcome!

This application includes a Flask backend for routing and rendering, Bootstrap for responsive UI, and a reusable Jinja layout structure.

What’s included

  • A Flask backend that handles routing, server-side logic, and page rendering
  • Bootstrap integration for responsive layouts and modern UI components
  • Reusable Jinja templates with a shared base.html layout
  • Organized frontend structure using templates, custom CSS, and JavaScript
  • Environment configuration through .env files for secure settings
  • A modular structure that separates models, templates, static assets, and backend logic

Project Structure

Backend (Python / Flask)

  • run.py → Main application entry point
  • routes.py → Flask routes and page logic
  • .env → Environment variables and secret configuration
  • .env.example → Example environment variable template
  • requirements.txt → Python dependencies
  • app/models/ → Database models and backend data structures
    • user.py → Example user model
    • __init__.py → Initializes the models package

Frontend (HTML / CSS / JavaScript)

  • templates/ → HTML templates rendered by Flask
    • base.html → Shared layout and structure
    • index.html → Main homepage
    • signin.html → Sign-in form
    • template.html → Reusable page template
  • static/ → Frontend assets
    • css/style.css → Custom styling
    • js/main.js → Client-side JavaScript

Other Project Files

  • README.md → Project documentation and setup instructions
  • .gitignore → Files and folders excluded from Git tracking

Quick Start

  1. Install packages: pip install -r requirements.txt
  2. Run the app: python run.py
  3. Open your browser to http://127.0.0.1:5000
  4. Start customizing routes, templates, and static assets
Tip: Check out the Sign In page to see how forms work.
